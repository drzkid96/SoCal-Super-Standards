SIGN BLOCK CATALOG

Each individual AutoCAD 2000 drawing contains direct sign-face geometry in modelspace, with its geometric center at the insertion origin. Insert the drawing externally to create a block named for its file. One drawing unit is one inch. Filled paths use editable SOLID hatches with open counters.

Start with master.dwg to browse the contact sheet. Use the individual drawings for insertion at original size. The master enlarges reference-size previews only. Separate rows preserve source variants and historic legends. The manifest identifies each source drawing, source handle and sizing condition.

Reference size unknown folders contain symbols normalized to a 1.000-inch face width. The original physical dimensions are unknown. Source dimensions come from the drawing. Published dimensions give the cited application or road class.

The chart prints the source designation exactly. DWG-forbidden characters are transliterated in native block names. Source and size qualifiers distinguish separate blocks sharing a designation, including when several are inserted into one plan.
