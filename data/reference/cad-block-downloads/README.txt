SIGN BLOCK CATALOG

Each individual AutoCAD 2000 drawing holds two entities: one sign block inserted at 0,0, the lower-left corner of its sign legend table cell (1.025 x 1.2 in), and one MTEXT with the sign code, ROMANS, centered under the face. The face is scaled to fit the cell, so cells tile directly into a plan sign legend. One drawing unit is one plotted inch. Filled paths use editable SOLID hatches with open counters.

The master drawing (master.dwg, a separate download beside this archive) is the contact sheet; it keeps every face at its original size for details. The master enlarges reference-size previews only. Separate rows preserve source variants and historic legends. The manifest identifies each source drawing, source handle and sizing condition.

size-unknown folders contain symbols normalized to a 1.000-inch face width. The original physical dimensions are unknown. Source dimensions come from the drawing. Published dimensions give the cited application or road class.

The chart prints the source designation exactly. DWG-forbidden characters are transliterated in native block names. Source and size qualifiers distinguish separate blocks sharing a designation, including when several are inserted into one plan.
