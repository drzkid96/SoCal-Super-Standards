<details class="ocr"><summary>Drawing Notes &amp; Specifications</summary>
<h5 class="dwg-sub">Column placement with angle parking</h5>
<p>Angle below 65 degrees to be as shown.</p>
<p>Angle 65 degrees to 75 degrees to be as shown.</p>
<p>Any angle greater to use 90 degree standard. (See sheet no. 1.)</p>
<h5 class="dwg-sub">Notes</h5>
<ol class="dwg-notes">
<li value="1">No columns to be placed in cross-hatched areas.</li>
<li value="2">No columns to be placed to the rear of any portion of any space.</li>
</ol>
