<h5 class="dwg-sub">Notes</h5>
<p>* If median width is less than 3 feet, use <a class="sref" href="/SoCal-Super-Standards/signs/r4-7/" data-svg="/SoCal-Super-Standards/signs/R4-7.svg">R4-7</a> (18&quot; x 24&quot;) sign and OM3-L object marker.</p>
<p>All regulatory and warning signs shall be minimum 0.063 inch thick and have 3M high intensity prismatic sheeting (Series #3930) with 3M premium protective overlay film (Series #1160).</p>
<div class="dwg-callouts"><strong>Callouts:</strong> Secure sign with drive rivet. Install <a class="sref" href="/SoCal-Super-Standards/signs/w12-1/" data-svg="/SoCal-Super-Standards/signs/W12-1.svg">W12-1</a> sign (24&quot; x 24&quot;) or <a class="sref" href="/SoCal-Super-Standards/signs/r4-7/" data-svg="/SoCal-Super-Standards/signs/R4-7.svg">R4-7</a> sign (24&quot; x 30&quot;)*. Install type <a class="sref" href="/SoCal-Super-Standards/signs/om1-3/" data-svg="/SoCal-Super-Standards/signs/OM1-3.svg">OM1-3</a> yellow object marker (24&quot; x 24&quot;)*. 2&quot;x2&quot; square post (12 gage). 3/8&quot; holes, insert sign post and fasten with rivets. Existing (EXIST.) concrete or asphalt paving. Existing (EX.) concrete curb and gutter. EX. asphalt paving. 2-1/4&quot; x 2-1/4&quot; square heavy duty galvanized anchor sleeve (Telespar or equal). (Not to scale.)</div>
