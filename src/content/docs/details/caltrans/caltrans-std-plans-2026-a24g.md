<p class="dwg-sum" data-pagefind-weight="6">Wrong way countermeasures at freeway exit ramps: a Type V arrow with red retroreflective Type R markers, and yield line and limit (stop) line layouts shown with non-recessed and recessed Type R markers. Marker spacing, offsets and Type R marker dimensions are given. A note places Type R markers in front of the first line when there is a crosswalk at the ramp end.</p>

<details class="sdesc" open><summary>What this sheet shows</summary><p>Type V arrow at exit ramp: a long narrow arrow stem 1&#x27;-0&quot; wide (shown with 2&quot; offsets each side of the centerline to the markers) ending in a Y shaped head formed by two diverging legs. The arrow is A=33 ft2. The tip of the arrow is 24&#x27;-0&quot; from the base end. The head legs are each 9&#x27;-0&quot; long and 1&#x27;-0&quot; wide, with a 2&#x27;-0&quot; overall stem width at the junction. Type R markers are placed in pairs along both sides of the stem at 4&#x27;-0&quot; on center (O/C) typical, starting from the base, with the marker rows 2&quot; each side of the centerline. Dimensions up the stem from the base are 12&#x27;-0&quot;, 17&#x27;-6&quot; and 24&#x27;-0&quot;, with a 2&quot; dimension at the stem top and at the arrow tip. A note on the drawing says when recessed, use one marker at this location (at the tip). A single marker sits at the tip and a pair at the junction of the head.</p>
<p>Yield line at exit ramp (markers are not recessed): a row of white isosceles triangles (a series) pointing in the direction of the approaching vehicle, each 2&#x27;-0&quot; wide at the base and 3&#x27;-0&quot; long, spaced 1&#x27;-0&quot; apart (typical). A Type R marker, with a red reflective face and blank back, is mounted 2&quot; (typical) above the base of each triangle, aimed with the marker faces at 45 degrees each side of the centerline. The row is shown with a direction of travel arrow.</p>
<p>Yield line at exit ramp (markers are recessed): the same row of white isosceles triangles, 2&#x27;-0&quot; wide at the base (typical), 3&#x27;-0&quot; long (typical), spaced 1&#x27;-0&quot; apart (typical). A row of single Type R markers is placed 3&#x27;-0&quot; (typical) beyond the triangle base, one marker aligned with each triangle, with the marker faces red reflective and blank. Triangle series is described as white series of isosceles triangles.</p>
<p>Limit line (stop line) at exit ramp (markers are not recessed): a white limit line 1&#x27;-0&quot; to 2&#x27;-0&quot; wide (limit line or crosswalk), with Type R markers placed 2&quot; (typical) in front of the line at 4&#x27;-0&quot; (typical) spacing. Each marker has the faces set at 45 degrees each side, red reflective and blank.</p>
<p>Limit line (stop line) at exit ramp (markers are recessed): a 1&#x27;-0&quot; white line with a row of single Type R markers placed 3&#x27;-0&quot; (typical) from the line at 4&#x27;-0&quot; (typical) spacing.</p>
<p>Yield line: a plain row of white isosceles triangles, each 2&#x27;-0&quot; wide and 3&#x27;-0&quot; long (typical) with 1&#x27;-0&quot; spacing (typical).</p>
<p>Limit line (stop line): a single white transverse line 1&#x27;-0&quot; to 2&#x27;-0&quot; wide with break lines.</p>
<p>Type R marker details: a plan and a side profile of the marker. The marker is 3 7/8 in. to 4 1/2 in. long by 1 7/8 in. to 4 1/8 in. wide (as dimensioned: 3 7/8&quot;-4 1/2&quot; and 1 7/8&quot;-4 1/8&quot;) and 3/8 in. to 3/4 in. high. A hatched area shows the retroreflective face on the backside.</p>
<p>Legend: a square marker symbol means Type R one-way red retroreflective marker.</p></details>
<details class="ocr" open><summary>Notes on this sheet (cleaned from the PDF text)</summary><p>Legend: Type R one-way red retroreflective marker (symbol shown).</p>
<p>1. If there is crosswalk at the end of the exit ramp, place Type R markers in front of the first line for wrong way vehicle that travels up the ramp with the red reflective side facing the intersection.</p></details>
