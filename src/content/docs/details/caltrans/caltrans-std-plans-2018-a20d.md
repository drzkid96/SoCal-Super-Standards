<p class="dwg-sum" data-pagefind-weight="6">Revised Caltrans 2018 standard plan RSP A20D covers channelizing lines, the 6" bike lane line and its 200'-0" intersection line, lane and center line extensions through intersections, recessed traffic stripes and recessed retroreflective pavement markers. It supersedes the A20D dated May 31, 2018.</p>

<p>Channelizing line: <a class="sref dref" href="/SoCal-Super-Standards/markings/line-types/#detail-38" data-svg="/SoCal-Super-Standards/linetypes/detail-38.svg">Detail 38</a> is an 8&quot; white line with Type G markers at 24&#x27;-0&quot; spacing along the line with a 2&quot; offset, and through traffic shown by an arrow. <a class="sref dref" href="/SoCal-Super-Standards/markings/line-types/#detail-38a" data-svg="/SoCal-Super-Standards/linetypes/detail-38a.svg">Detail 38A</a> is a plain 8&quot; white line. <a class="sref dref" href="/SoCal-Super-Standards/markings/line-types/#detail-38b" data-svg="/SoCal-Super-Standards/linetypes/detail-38b.svg">Detail 38B</a> is an 8&quot; white line with Type C markers on both sides at 24&#x27;-0&quot; spacing, 2&quot; offset each side. Detail 38C is deleted. <a class="sref dref" href="/SoCal-Super-Standards/markings/line-types/#detail-38d" data-svg="/SoCal-Super-Standards/linetypes/detail-38d.svg">Detail 38D</a> (exit ramps only) is an 8&quot; white line with Type C markers at 24&#x27;-0&quot; spacing and a 2&quot; offset.</p>
<p>Bike lane line: <a class="sref dref" href="/SoCal-Super-Standards/markings/line-types/#detail-39" data-svg="/SoCal-Super-Standards/linetypes/detail-39.svg">Detail 39</a> is a 6&quot; white line. Intersection line, bike lane: <a class="sref dref" href="/SoCal-Super-Standards/markings/line-types/#detail-39a" data-svg="/SoCal-Super-Standards/linetypes/detail-39a.svg">Detail 39A</a> shows a 6&quot; white line transitioning to a dashed line over 200&#x27;-0&quot; before the intersection, with 8&#x27;-0&quot; dashes and 4&#x27;-0&quot; gaps.</p>
<p>Lane line extensions through intersections: <a class="sref dref" href="/SoCal-Super-Standards/markings/line-types/#detail-40" data-svg="/SoCal-Super-Standards/linetypes/detail-40.svg">Detail 40</a> shows 6&quot; white dashes 6&#x27;-0&quot; long with 1&#x27;-0&quot; gaps. Detail 40A is deleted. Center line extensions through intersections: <a class="sref dref" href="/SoCal-Super-Standards/markings/line-types/#detail-41" data-svg="/SoCal-Super-Standards/linetypes/detail-41.svg">Detail 41</a> shows 6&quot; yellow dashes with the same 1&#x27;-0&quot; and 6&#x27;-0&quot; dimensions. Detail 41A is deleted.</p>
<p>Legend: Markers: Type C red-clear retroreflective, Type G one-way clear retroreflective. Line: 6&quot; yellow line. Marker details for Type C and Type G are 3 7/8&quot; to 4 1/8&quot; wide, 3/8&quot; to 3/4&quot; high and 1 7/8&quot; to 4 1/8&quot; long, with a hatched retroreflective face.</p>
<p>Detail for recessed traffic stripe: section showing a 6&quot; to 8&quot; wide striping material placed in a recess flush with the finished roadway surface on both sides.</p>
<p>Recess detail for retroreflective pavement marker: Type 1 recess plan has a 2&#x27;-0&quot; minimum approach, a 1&#x27;-0&quot; minimum recess and marker at the downstream end of the recess, and Section B-B shows the marker at the downstream end of recess 0 to 3/16&quot; below the surface. Type 2 recess plan has 2&#x27;-0&quot; minimum, 1&#x27;-0&quot; minimum and 2&#x27;-0&quot; minimum with the marker at the center of recess, Section A-A. The recess width is 5 3/16&quot; +/- 1/8&quot; and depth is variable (Var.).</p>
<p>Retroreflective pavement marker for recessed installation: Types C, RY and D (two-way) and Types G, R and H (one-way) shown in side and plan view. Width is 4 9/16&quot; to 4 13/16&quot;, height 3/8&quot; to 7/16&quot;, length 2&quot; to 2 1/2&quot;. Retroreflective face is hatched.</p>

<details class="ocr" open><summary>Notes on this sheet (cleaned from the scan)</summary><h5>Recessed notes:</h5>
<p>A. See typical traffic line details for pavement marking patterns.</p>
<p>B. See standard specifications for recess depth and recess striping material thickness.</p>
<h5>Recessed marker notes:</h5>
<p>1. See typical traffic line details for marker patterns to be used with recessed pavement markers.</p>
<p>2. The retroreflective pavement markers shown for recessed installations are not to be used for non-recessed installations.</p>
<p>3. The top of pavement markers installed in recesses shall be 0 to 3/16 inch below the pavement surface.</p>
<p>4. Use Type 1 recess for pavement markers with one-way retroreflective face. Use Type 2 recess for pavement markers with two-way retroreflective face.</p>
<p>RSP A20D dated October 19, 2018 supersedes Standard Plan A20D dated May 31, 2018, page 15 of the Standard Plans book dated 2018.</p>
<p>Deleted details: 38C, 40A and 41A.</p>
<p>Legend: Markers: Type C red-clear retroreflective. Type G one-way clear retroreflective. 6&quot; yellow line.</p></details>
