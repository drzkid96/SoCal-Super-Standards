<details class="ocr"><summary>Drawing Notes &amp; Specifications</summary>
<div class="dwg-callouts"><strong>Note:</strong> Pavement markers shown off the solid line may be placed on the line.</div>
<h5 class="dwg-sub">Recessed notes</h5>
<p>A. See typical traffic line details for pavement marking patterns.</p>
<p>B. See Standard Specifications for recess depth and recess striping material thickness.</p>
<h5 class="dwg-sub">Recessed marker notes</h5>
<ol class="dwg-notes">
<li value="1">See typical traffic line details for marker patterns to be used with recessed pavement markers.</li>
<li value="2">The retroreflective pavement markers shown for recessed installations are not to be used for non-recessed installations.</li>
<li value="3">The top of pavement markers installed in recesses shall be 0 in. to 3/16 in. below the pavement surface.</li>
<li value="4">Use Type 1 recess for pavement markers with one-way retroreflective face. Use Type 2 recess for pavement markers with two-way retroreflective face.</li>
<li value="5">For exit ramps, use Type 1 recess for Type R markers with one-way retroreflective face. Reverse the orientation of the recess and place the marker at the upstream end of the recess.</li>
</ol>
<h5 class="dwg-sub">Legend</h5>
<ul class="dwg-legend">
<li>Type C red-clear retroreflective marker.</li>
<li>Type G one-way clear retroreflective marker.</li>
<li>6 in. yellow line.</li>
<li>Details 38C, 40A and 41A are marked deleted.</li>
</ul>
