<p class="dwg-sum" data-pagefind-weight="6">Guidance page on raised crossing drainage, covering sidewalk culverts and the Case C option that keeps existing gutter flow. The culvert follows BOE Standard Plan S-322 (at least 4 in of depth) or DL-2327 (may need more depth for a concrete lid). Case C uses a transverse ramp limited to 5 percent slope, so it applies only to streets with cross slope up to 3.33 percent and unrestricted on-street parking, and the raised crossing is 2 in to 4 in above existing pavement.</p>

<details class="ocr" open><summary>Notes on this sheet (cleaned from the PDF text)</summary><p>The design of the sidewalk culvert should follow BOE Standard Plan S-322, which requires a depth of at least 4&quot; to install the culvert, or BOE Standard Plan DL-2327 which may require additional depth to accommodate a concrete lid. See Maintenance Considerations for more information on maintenance of sidewalk culverts. The street should be designed such that the sidewalk culvert is visible to all street users. Flexible delineator posts and/or pavement marking should be used upstream of the raised crossing to ensure motorists and bicyclists do not inadvertently use this space (see LADOT Standard Plan 483.1).</p>
<p>6.5.4.3 Case C - Existing Gutter Flow</p>
<p>Where Case A is not feasible, and where a Case B is not desirable, the existing gutter flow should be maintained by sloping the raised crossing down to match the edge of the gutter (see Figure 6-11). This is achieved by using a transverse ramp. This design is only feasible where there is unrestricted (by time of day) on-street parking, which ensures that the transverse ramp occurs outside of the travel lane.</p>
<p>The slope of the transverse ramp is limited to 5%. Therefore, this design is only applicable to streets with an existing cross slope not exceeding 3.33%. On streets with a cross slope exceeding 3.33%, the transverse ramp will not be able to achieve a raised crossing within the parking area.</p>
<p>When this design is feasible, a full height raised crossing may not be achievable. The raised crossing should be between 2&quot; and 4&quot; above the existing pavement. The sidewalk should meet the existing gutter elevation by using a curb ramp. The sidewalk should not be depressed with this design, which would lower the existing curb height, resulting in a wider gutter pan to achieve sufficient stormwater flow capacity.</p>
