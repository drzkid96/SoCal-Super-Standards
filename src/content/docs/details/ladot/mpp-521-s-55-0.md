<p>Legend: Flashing beacon activated by pedestrian push button (beacon symbol at top left).</p>
<h5 class="dwg-sub">Notes</h5>
<ol class="dwg-notes">
<li value="1">The flash pattern utilizes LED heads and a Model 2070 controller. There are 60 flash periods per minute. The flash period for each beacon includes three pulses within 0.5 seconds and a pause of 0.5 seconds. The pulses of one beacon alternate with the pause of the other beacon, as shown below.</li>
<li value="2">Flash length is W/3.5 seconds and retimes with each call. (W is the roadway width dimension shown on the plan.)</li>
<li value="3">See <a href="/SoCal-Super-Standards/details/ladot/mpp-531-s-481-0/">S-481.0</a> for required advance signing, pavement marking, and red curb.</li>
<li value="4">At school crossings, school related signs and pavement markings shall be used in place of those shown hereon, as per <a href="/SoCal-Super-Standards/details/ladot/mpp-531-s-481-0/">S-481.0</a>.</li>
</ol>
<p>Sign and drawing labels on the plan: <a class="sref" href="/SoCal-Super-Standards/signs/w11-2/" data-svg="/SoCal-Super-Standards/signs/W11-2.svg">W11-2</a>, <a class="sref" href="/SoCal-Super-Standards/signs/w11-2/" data-svg="/SoCal-Super-Standards/signs/W11-2.svg">W11-2</a>(mod), W16(mod), <a class="sref" href="/SoCal-Super-Standards/signs/w11-2/" data-svg="/SoCal-Super-Standards/signs/W11-2.svg">W11-2</a>&#x27;s and <a class="sref" href="/SoCal-Super-Standards/signs/w16-7p/">W16-7p</a>&#x27;s, <a class="sref" href="/SoCal-Super-Standards/signs/r1-1/" data-svg="/SoCal-Super-Standards/signs/R1-1.svg">R1-1</a>, <a class="sref" href="/SoCal-Super-Standards/signs/r1-5/" data-svg="/SoCal-Super-Standards/signs/R1-5.svg">R1-5</a>, <a class="sref" href="/SoCal-Super-Standards/signs/r9-3a/" data-svg="/SoCal-Super-Standards/signs/R9-3a.svg">R9-3a</a>&#x27;s, <a class="sref" href="/SoCal-Super-Standards/signs/r9-3bp/">R9-3b</a>&#x27;s, R62E(CA) PPB, 20&#x27; Mastarm, Detail &quot;A&quot;, FL.Y (flashing yellow).</p>
