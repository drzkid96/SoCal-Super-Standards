<p class="dwg-sum" data-pagefind-weight="6">Shows a typical installation of a Type 337 post-top mounted signal cabinet on a Type 8 shaft with a slip fitter and a Type F-8 foundation. The cabinet is mounted with its doors perpendicular to the curb and swinging toward the curb. The shaft is set 36 in from the curb face with a 3 in conduit at 14 in min.</p>

<p>Detail: door openings on Type 337 PTM cabinet shown relative to the curb face.</p>
<p>Typical cabinet installation (Type 337 post-top mounted cabinet): slip fitter, Type 8 shaft, Foundation Type F-8, 3 in conduit.</p>
<p>Dimensions: 36 in from curb face to shaft, 14 in min. conduit depth.</p>
