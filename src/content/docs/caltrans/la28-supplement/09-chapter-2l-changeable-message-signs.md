<p>CHAPTER 2L. CHANGEABLE MESSAGE SIGNS</p>
<p><a href="/SoCal-Super-Standards/s/ca/2L.01/">Section 2L.01</a> Description of Changeable Message Signs The following is added to this section:</p>
<h4>Standard:</h4>
<p>09 If used, provisions of Chapter 2G and Chapter 2L of CA MUTCD 2026 and this Supplement LA28 shall apply to changeable message signs used in GRN dedicated lane(s) for Olympic Games vehicles to travel between venues that is included in the established GRN. Such GRN lanes shall use changeable message signs or changeable message elements within static signs to display the appropriate regulatory sign messages only when they are in effect. Support:</p>
<p>10 Refer to Sections 1D.08, 2G.01, and 2G.06, Figures 2G-8(LA28), 2G-9(LA28), and Tables 1D-101(LA28), 2A-2, and 2A-2(LA28) of CA MUTCD 2026 and its LA28 Supplement for more details on changeable message sign applications in GRN dedicated lane(s) for Olympic Games vehicles to travel between venues that is included in the established GRN.</p>
<p><a href="/SoCal-Super-Standards/s/ca/2L.02/">Section 2L.02</a> Applications of Changeable Message Signs The following is added to this section:</p>
<p>Option:</p>
<p>02a Any existing or new changeable message signs or portable changeable message signs may be used to display GRN messages, where engineering judgment determines the need to use GRN messages on GRN roadways to facilitate travel during LA28 games. Support:</p>
<p>02b Proposed GRN messages used on the changeable message signs and portable changeable message signs, such as LA28 PERMIT ONLY, LA28 PERMIT ONLY AHEAD, and LA28 PERMIT ONLY LEFT LANE are transportation-related messages. Standard:</p>
<p>02c GRN messages used on changeable message signs shall be used only if the changeable message signs or the portable changeable message signs are located in or on approaches to GRN dedicated lane(s) for Olympic Games vehicles to travel between venues that is included in the established GRN. Messages must conform to message requirements, including those for abbreviations, included in Parts 1 and 2.</p>
<p><a href="/SoCal-Super-Standards/s/ca/2L.05/">Section 2L.05</a> Message Length and Units of Information The following is added to this section:</p>
<p>Guidance:</p>
<p>12 When a CMS is used to display a GRN message, the message should be simple, direct, brief, legible, and clear (see <a href="/SoCal-Super-Standards/s/ca/1D.01/">Section 1D.01</a>). GRN messages should be relevant to the road user on the roadway that is included in the established GRN, on which the message is displayed.</p>
<p>13 The GRN message should be appropriately shortened or otherwise modified to comply with the provisions of <a href="/SoCal-Super-Standards/s/ca/2L.05/">Section 2L.05</a> when it is displayed on a CMS.</p>
<p>14 The GRN message should be similar to the static GRN regulatory and guide sign legends that are included in CA MUTCD 2026 LA28 Supplement in Chapter 2G. Support:</p>
<p>15 Table 2L-101(LA28) provides examples of GRN messages for CMS that can be used in GRN dedicated lane(s) for Olympic Games vehicles to travel between venues that is included in the established GRN.</p></div>
